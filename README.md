# Eco Cleaners BD

A responsive marketing and booking site for Eco Cleaners BD, a Dhaka eco-friendly home cleaning service. Visitors can browse ready monthly packages, build a custom plan with a live price summary, and send a booking request by form or WhatsApp.

Built with [Arc Studio](https://studio.arc.io)

## Tech stack

- React, TypeScript, Vite
- Tailwind CSS
- Lucide icons, Framer Motion, Sonner toasts

## Development

Prerequisites: [Bun](https://bun.sh).

```sh
bun install
bun run dev
bun run check   # lint and typecheck
```

### Environment variables

None.

### Business details

The WhatsApp number, phone and email shown on the site are placeholders. Replace them in `src/data/catalog.ts` before launch.
